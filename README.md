# Hyprland Dotfiles

A curated collection of personal dotfiles and configuration files for a modern, efficient Hyprland setup.

## 📋 Overview

This repository contains my personal configuration files for [Hyprland](https://hyprland.org/). 
Note that these are optimised for my full AMD system and are used alongside [caelestia-shell](https://github.com/caelestia-dots/shell)

## 🎯 Contents

- **Hyprland Configuration** — Window management, keybindings, and workspace setup
- **Fastfetch** — Configurations for Fastfetch
